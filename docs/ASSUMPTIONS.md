# Assumptions about Telegram behaviour

Statuses: `unverified` (not checked against a source), `verified-in-docs` (confirmed in the official Telegram Bot API / Mini Apps documentation), `needs-device-test` (can only be confirmed on a real iOS / Android / Desktop client).

**Verification limit in Sprint 1.** The sandbox this work was done in cannot reach `core.telegram.org` (the outbound proxy answers 403), so nothing could be checked against the official pages. Items below marked `unverified` were implemented from PRD 4.3 / 7.5 and general knowledge and **must be checked against the official docs before release**. The PRD (7.5) states that a first group of Mini Apps methods was checked on 2026-10-09; those are carried over as `verified-in-docs (per PRD 7.5)` and were not re-checked here. Nothing in this file has been tested on a device.

Last updated: Review round 2 (after Sprint 1). In round 2 the product owner checked A-01b on the official page; this agent still cannot reach `core.telegram.org`.
